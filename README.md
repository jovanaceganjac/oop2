# Object-Oriented Programming 2 — Java AWT

Exam and lab tasks for *Object-Oriented Programming 2* at ETF Belgrade:
small graphical simulations and games in **Java AWT** with threads.

| Folder | Task |
|---|---|
| `v1` | vacuum-cleaner simulation on a canvas |
| `popravniv1` | pipe-laying puzzle on a grid |
| `popravniv2` | brick-breaker style game with animated ball (threads) |
| `popravniv3` | grid game with a player, walls and passages |
